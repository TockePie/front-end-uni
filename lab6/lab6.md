# Лабораторна робота №6

## Відомості

### Тема

JavaScript. Формат JSON. API. Отримання даних із зовнішньої сторінки (fetch, promise).

### Мета

Навчитися працювати з даними у форматі JSON, отримувати та обробляти інформацію із зовнішнього API за допомогою методів **fetch** та **Promise**, а також відображати отримані дані на вебсторінці.

## Хід виконання роботи

### Завдання

1. Отримати дані із зовнішнього ресурсу [https://randomuser.me/api](https://randomuser.me/api) за допомогою `fetch()` та `Promise`.
2. Вивести на сторінку інформацію згідно з **варіантом №9**:

   - picture (фото)
   - name (ім’я)
   - cell (мобільний номер)
   - city (місто)
   - postcode (поштовий індекс)

3. Отримання даних має виконуватись після натискання кнопки.

## Результати

Після натискання кнопки "Отримати користувача" на сторінці з’являється фото та дані випадково згенерованого користувача.

![alt text](image.png)

### Пояснення

1. Після натискання кнопки викликається функція `getUser()`.
2. Усередині функції створюється **власний об’єкт Promise**, який виконує `fetch()`-запит до API `https://randomuser.me/api`.
3. Отримані дані у форматі JSON розбираються (`response.json()`), після чого з них вибираються потрібні поля відповідно до **варіанта №9**.
4. Результат виводиться в HTML-блок `#userInfo`.
5. При помилках запиту в консоль виводиться повідомлення з `catch()`, а кнопка знову стає активною.
